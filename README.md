# GymBro Lite

Diario di allenamento installabile su iPhone: schede, serie e pesi, progressi, corsa.
Funziona offline. I dati restano solo sul telefono (usa "Esporta backup" nella sezione Schede).

## Installare sull'iPhone
1. Apri il link della pagina in **Safari**.
2. Tocca **Condividi** → **Aggiungi alla schermata Home** → **Aggiungi**.
3. Apri GymBro dall'icona: si avvia a schermo intero, anche senza internet.

## Pubblicare con GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
Dopo un minuto la pagina è su `https://<utente>.github.io/<repository>/`.

## Aggiornare
Sostituisci i file e cambia `VERSIONE` in `sw.js`. L'iPhone scarica la nuova versione
quando apri l'app con internet; la vedi all'apertura successiva.
